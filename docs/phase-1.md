# Phase 1 — GitHub Repository + Project Skeleton

## Objective

Set up the GitHub repository and establish a clean, organized project structure that can support the complete development, experimentation, evaluation, documentation, and final submission workflow.

---

## 1. GitHub Repository

A GitHub repository was created for the project.

The repository is used to:

- Maintain the project source code.
- Track development progress using Git.
- Store project documentation.
- Maintain notebooks and experimentation work.
- Organize dataset-related work.
- Record important project decisions.
- Maintain a reproducible project structure.
- Provide the final project for submission and review.

---

## 2. Project Structure

A structured project directory was created to keep different types of project artifacts organized.

The project contains dedicated areas for:

- Documentation
- Architecture and design decisions
- API documentation
- Security documentation
- Testing documentation
- Performance documentation
- Deployment documentation
- Notebooks and exploratory work
- Source code
- Dataset-related files
- Project configuration

## 3. Document Organisation

Documentation was treated as an important part of the project from the beginning.

Phase-specific documentation is maintained to record:

Work completed during each phase.
Important observations.
Decisions made during development.
Results obtained from experiments.
Changes in the project direction.
Reasoning behind important decisions.

A separate decision log is maintained for important project decisions and the reasoning behind them.

This allows the project development process to be understood and reproduced later.

Status: COMPLETED

The GitHub repository and initial project skeleton were established. The repository was organized into appropriate directories for documentation, development, experimentation, and project artifacts. Git was adopted for version control and incremental development.

The project can proceed with the dataset-focused phases of the roadmap.
