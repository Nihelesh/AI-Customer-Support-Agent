# AI Customer Support Agent

## Overview

An AI Customer Support Agent which reads customer's message, understands problem, indetify intent, find similar past conversations, draft reponse, checks whether this problem can be resolved by the AI or human is required.

## Problem Statement

A company has a customer support team which receives thousands of conversations. Humans have to do repeated tasks like read message, understand problem, search previous cases, write response and decides whether escalation is required.

Humans need to do this repetitive work which consumes their time and effort.

## Project Goals

1. Understand customer's intent
2. What should AI reply?
3. Should AI answer or should human answer?
